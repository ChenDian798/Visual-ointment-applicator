# 可视涂药笔交互展示

运行：`npm install`，然后 `npm run dev`。发布构建：`npm run build`，将 dist 部署为静态网站。

功能：旋转缩放、蓝白/黑银材质切换、头部设计切换（v4 斜切锥形 / v3 平头）、整体/头部/底部/结构透视/握持与视野/拆装视角，以及按钮按压演示。全部视角来自同一 Three.js 场景模型，页面文案为英语。

模型在 src/applicator.js 中以毫米建立：机身直径 20 mm、标称总长 126 mm、壳厚 1.2 mm。电池、PCB 与摄像头为明确尺寸的设计包络，尚未匹配实际元件。并非制造 CAD，不能用于生产或证明实际成像性能。

运行 `node verify-model.mjs` 检查视野投影、按钮齐平、内部包络和视角几何一致性。模拟摄像头画面来自同一个三维场景。设计参数与样机验证清单见 design-review-v3.md。

结构透视会隐藏内部观察的遮挡装饰，并以低透明度显示外壳；底部端盖保留唯一轴向USB-C接口。所有模式共享镜头与棉签的相对位置。
